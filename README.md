# Agri Desk — تحديثات Windows

هذا المستودع مخصص لملفات التثبيت والتحديث المنشورة فقط.

- أول تثبيت: افتح أحدث إصدار مستقر من [Releases](../../releases) وثبّت ملف `Agri-Desk-Setup-…-x64.exe`.
- بعد تثبيت نسخة تدعم التحديثات، يفحص البرنامج الإصدار عند التشغيل ويحمّل التحديث بالخلفية، ويثبّته عند الإغلاق الطبيعي.
- رقم الإصدار وحالة التنزيل يظهران في الإعدادات. لا تحتاج حساب GitHub على جهاز المستخدم.
- تبقى بيانات الشركة وحساباتها في مصدر البيانات نفسه.

كل إصدار يحتوي ملف التثبيت، وملف `.exe.blockmap` للتنزيل التفاضلي، و`latest.yml`. يجب نشر الملفات الثلاثة من البناء نفسه مع الاحتفاظ بالإصدارات السابقة.

الكود المصدري وملفات قاعدة البيانات ليست ضمن هذا المستودع. ملفات التثبيت وحدها لا تمنح أي شخص صلاحية الوصول إلى بيانات الشركة.
